# 🤖 بوت استقبال المحتوى (Telegram Submissions Bot)

بوت تيليغرام بالعربية لاستقبال المحتوى من المستخدمين بعد اشتراكهم الإجباري بقناة.
كل مشاركة (Submission) = نص (حتى 500 حرف) + روابط + صور + فيديوهات، تُحفظ في قاعدة بيانات ويراجعها الأدمن من لوحة إدارة داخل تيليغرام.

## التقنيات المستخدمة

| المكوّن | الاختيار |
|---|---|
| Python | 3.11 أو أحدث (مُوصى به 3.12) |
| إطار تيليغرام | `aiogram` 3.x (async) |
| قاعدة البيانات | SQLite عبر `SQLAlchemy 2.0` (async) + `aiosqlite` |
| الإعدادات | `python-dotenv` (ملف `.env`) |

> الانتقال لاحقاً إلى PostgreSQL يتم بتغيير `DATABASE_URL` فقط (انظر القسم الأخير).

---

## 1) المتطلبات

- Python 3.11+ ( تأكد بالأمر `python --version` أو `python3 --version` )
- حساب تيليغرام + قناة (عامة أو خاصة) أنت مالكها أو أدمن فيها

## 2) تثبيت Python

- **Windows:** حمّل من https://www.python.org/downloads/ وفعّل خيار *Add Python to PATH* أثناء التثبيت.
- **macOS:** `brew install python`
- **Ubuntu/Debian:** `sudo apt update && sudo apt install python3 python3-venv python3-pip`

## 3) تثبيت المكتبات

```bash
cd project
python -m venv .venv

# تفعيل البيئة الافتراضية
source .venv/bin/activate          # Linux / macOS
# .venv\Scripts\activate           # Windows (PowerShell/CMD)

pip install -r requirements.txt
```

## 4) إنشاء البوت من BotFather

1. افتح @BotFather في تيليغرام وأرسل `/newbot`.
2. اختر اسماً واسم مستخدم ينتهي بـ `bot`.
3. انسخ الـ **Token** (شكله `123456789:AA...`) — هذا هو `BOT_TOKEN`. **لا تشاركه مع أحد.**

## 5) إضافة البوت Administrator في القناة (إلزامي)

بدون هذه الخطوة البوت لا يستطيع فحص عضوية المستخدمين.

1. افتح القناة ← *Administrators* ← *Add Administrator*.
2. ابحث عن البوت وأضفه (يكفي أقل الصلاحيات؛ لا يحتاج نشر رسائل).

## 6) الحصول على CHANNEL_ID

- **قناة عامة:** استخدم `@username` الخاص بالقناة مباشرة (مثال: `CHANNEL_ID=@mychannel`).
- **قناة خاصة (أو للحصول على الرقم):** حوّل أي رسالة من القناة إلى بوت مثل `@RawDataBot` أو `@getidsbot` وانسخ `chat id` — يكون رقماً سالباً يبدأ بـ `-100` مثل `-1001234567890`.

`CHANNEL_URL` هو رابط القناة الذي يفتحه زر "اشترك بالقناة"، مثل `https://t.me/mychannel`
(للقناة الخاصة استخدم رابط الدعوة `https://t.me/+xxxxxxxx`).

## 7) إعداد ملف `.env`

```bash
cp .env.example .env        # Windows: copy .env.example .env
```

عدّل الملف:

```env
BOT_TOKEN=123456789:AAxxxxxxxxxxxxxxxxxxxxxxxx
CHANNEL_ID=-1001234567890
CHANNEL_URL=https://t.me/mychannel
ADMIN_IDS=111111111
```

### إضافة ADMIN_IDS

- الـ ID الرقمي لحسابك: أرسل رسالة إلى `@userinfobot` وانسخ `Id`.
- لعدة أدمن افصل بفاصلة: `ADMIN_IDS=111111111,222222222`
- الأدمن يفتح اللوحة بالأمر `/admin` (أو زر "🛠 لوحة الإدارة" الذي يظهر له في القائمة الرئيسية).

### باقي الإعدادات (كلها قابلة للتعديل)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `MAX_TEXT_LENGTH` | 500 | الحد الأقصى للنص (الروابط لا تُحسب) |
| `MAX_MEDIA_PER_SUBMISSION` | 5 | أقصى عدد ملفات (صور + فيديوهات) |
| `MAX_IMAGE_SIZE_MB` | 10 | أقصى حجم للصورة |
| `MAX_VIDEO_SIZE_MB` | 50 | أقصى حجم للفيديو |
| `MAX_URLS_PER_SUBMISSION` | 10 | أقصى عدد روابط |
| `SUBMISSION_COOLDOWN_SECONDS` | 10 | الانتظار بين مشاركتين لنفس المستخدم |
| `PREVIEW_DELAY_SECONDS` | 1.5 | مهلة تجميع الرسائل/الألبوم قبل المعاينة |
| `DRAFT_TTL_MINUTES` | 30 | مدة بقاء مشاركة غير مكتملة |
| `TIMEZONE` | Asia/Damascus | المنطقة الزمنية لتواريخ الأدمن |
| `DATABASE_URL` | SQLite في `data/bot.db` | رابط قاعدة البيانات |
| `LOG_LEVEL` | INFO | مستوى السجلات |

## 8) تشغيل البوت

```bash
python main.py
```

عند النجاح سترى في الطرفية: `Bot started as @your_bot` و `Channel access verified.`
تُكتب السجلات أيضاً في `logs/bot.log` (التوكن يُحجب تلقائياً من السجلات).
لإيقاف البوت: `Ctrl + C`.

## 9) كيف تختبر كل ميزة

### الاشتراك الإجباري
1. من حساب **غير مشترك** بالقناة أرسل `/start` ← تظهر رسالة القفل 🔒 مع زرَّي "اشترك بالقناة" و"تحقق من الاشتراك".
2. اضغط "تحقق من الاشتراك" قبل الاشتراك ← رسالة ❌ "لسا ما اشتركت بالقناة".
3. اشترك بالقناة ثم اضغط "تحقق" ← ✅ "تم التحقق من اشتراكك" وتظهر الواجهة الرئيسية.
4. غير المشترك لا يستطيع فعل أي شيء آخر (أي رسالة أو زر يعيد له رسالة القفل).

> ملاحظة: الأدمن ليس معفى من الاشتراك. لاختبار الحالة بحسابك، اترك القناة مؤقتاً ثم أعد الاشتراك.

### إرسال نص
اضغط "✍️ إرسال محتوى" ← اكتب نصاً ← تظهر "📋 معاينة المحتوى" ← "✅ تأكيد وإرسال" ← رسالة النجاح.
اختبار الحد: أرسل نصاً أطول من 500 حرف ← "❌ النص طويل جداً" ولا يُحفظ شيء.
الروابط لا تُحسب: نص 480 حرفاً + رابط طويل = مقبول.

### روابط
أرسل رابط YouTube / Facebook / Instagram / TikTok / Threads / X ← تظهر في المعاينة باسم المنصة.
أرسل رابطاً من منصة أخرى (مثل `https://example.com/a`) ← ⚠️ تنبيه "منصة غير مدعومة" (لا يُحفظ الرابط ويبقى النص).

### صور
أرسل صورة عادية (مع Caption أو بدونه) ← المعاينة تعرض "1 صورة" والـ Caption يُعتبر النص.
اختبار الحد: أرسل أكثر من 5 ملفات ← "❌ لا يمكنك إرسال أكثر من 5 ملفات ضمن نفس المحتوى".

### فيديو
أرسل فيديو MP4/MOV كفيديو عادي ← المعاينة تعرض "1 فيديو". فيديو أكبر من الحد ← رسالة رفض.
(الملفات المرسلة "كملف/Document" أو GIF أو ملصقات ترفض برسالة توضيحية.)

### Album
حدد 3 صور معاً وأرسلها كألبوم ← تظهر **معاينة واحدة** فيها "3 صور"، وتُحفظ كمشاركة واحدة بثلاثة ملفات.
جرّب أيضاً مزيجاً: نص + صورة + رابط برسائل متتالية ← كلها في نفس المشاركة.

### الإلغاء وحد السرعة
- زر "❌ إلغاء" أو الأمر `/cancel` ← "❌ تم إلغاء عملية الإرسال" وتُحذف البيانات المؤقتة.
- بعد تأكيد مشاركة، حاول إرسال أخرى فوراً ← "⏳ استنى شوي قبل إرسال محتوى جديد".

### لوحة الإدارة
1. من حساب أدمن أرسل `/admin`.
2. **📩 الرسائل الجديدة**: تظهر المشاركات الأقدم أولاً، واحدة واحدة، مع المرفقات (ألبوم) وأزرار: ✅ تمت المراجعة / ❌ رفض / 🗑 حذف / ◀️ ▶️.
3. **📚 كل الرسائل**: قائمة بصفحات (8 في الصفحة) — اضغط على أي مشاركة لعرض تفاصيلها.
4. **📊 الإحصائيات**: المستخدمون، الإجمالي، الحالات، اليوم، آخر 7 أيام.
5. الحذف يطلب تأكيداً أولاً. حساب غير أدمن يضغط أزرار الإدارة يحصل على "⛔ غير مصرح لك".

## 10) بنية المشروع

```
project/
├── bot/
│   ├── main.py            # نقطة التشغيل + معالج الأخطاء العام
│   ├── config.py          # قراءة الإعدادات من البيئة
│   ├── texts.py           # كل النصوص العربية
│   ├── keyboards.py       # الأزرار (Inline Keyboards)
│   ├── middlewares.py     # بوابة الاشتراك + حماية الأدمن
│   ├── schemas.py         # كائنات بيانات بسيطة
│   ├── logging_config.py  # السجلات + حجب الأسرار
│   ├── handlers/          # start / user / submission / admin
│   ├── services/          # منطق العمل: drafts, subscription, submissions, admin_view
│   ├── database/          # database / models / repositories
│   └── utils/             # links / validation / formatting / text / telegram
├── .env.example
├── requirements.txt
├── README.md
└── .gitignore
```

الفصل واضح: **Handlers** (واجهة تيليغرام) ← **Services** (منطق العمل) ← **Repositories** (قاعدة البيانات)، و**Utils** و**Config** مستقلان.

### كيف تعمل المشاركة الواحدة؟
كل رسالة يرسلها المستخدم (نص، صورة، عنصر من ألبوم، رابط) تُضاف إلى **مسودة (Draft)** في الذاكرة. بعد مهلة قصيرة تُعرض معاينة واحدة، وعند "تأكيد وإرسال" يُعاد التحقق من كل شيء ثم تُحفظ المشاركة وملفاتها وروابطها في معاملة واحدة. الصور والفيديوهات لا تُنزَّل: يُحفظ فقط `file_id` لتيليغرام ويُستخدم لعرضها للأدمن.

### ملاحظات تصميمية
- النص المحفوظ في `submissions.text` هو النص **بعد إزالة الروابط منه**، والروابط تُحفظ في جدول `urls` مع اسم المنصة.
- التواريخ تُخزَّن بتوقيت UTC وتُعرض بالمنطقة الزمنية `TIMEZONE`.
- المسودات في الذاكرة: إعادة تشغيل البوت تُلغي المسودات غير المؤكدة فقط، أما المشاركات المؤكدة فمحفوظة في القاعدة.
- الجداول تُنشأ تلقائياً عند أول تشغيل (`create_all`). عند تغيير الجداول لاحقاً استخدم Alembic.

### إضافة ميزات لاحقاً (بدون إعادة كتابة)
| الميزة | أين تُضاف |
|---|---|
| زر نشر إلى قناة | زر جديد في `keyboards.submission_actions` + handler في `admin.py` (الحالة `published` موجودة أصلاً) |
| إشعار للأدمن عند وصول مشاركة | داخل `services/submissions.save_draft` بعد الحفظ |
| إشعار للمستخدم عند النشر | نفس handler النشر (`Submission.user.telegram_id` متوفر) |
| بحث / فلترة (منصة، تاريخ) | دوال جديدة في `repositories.py` (الجداول والفهارس جاهزة) |
| Tags | جدول جديد + علاقة في `models.py` |
| أكثر من أدمن | يعمل الآن: `ADMIN_IDS=1,2,3` |

## 11) الانتقال إلى PostgreSQL

1. أزل التعليق عن `asyncpg` في `requirements.txt` ثم `pip install -r requirements.txt`.
2. عدّل `.env`:
   ```env
   DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/botdb
   ```
3. شغّل البوت — تُنشأ الجداول تلقائياً. (لنقل بيانات SQLite القديمة استخدم أداة نقل مثل `pgloader`.)

## 12) استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| `البوت ما قدر يوصل للقناة` عند التشغيل | تأكد من `CHANNEL_ID` وأن البوت Administrator في القناة |
| كل المستخدمين يظهر لهم "لازم تشترك" حتى المشتركين | البوت ليس Administrator، أو `CHANNEL_ID` خاطئ — راجع `logs/bot.log` |
| زر الاشتراك لا يفتح شيئاً | `CHANNEL_URL` يجب أن يبدأ بـ `https://t.me/` |
| `ADMIN_IDS is empty` | أضف الـ ID الرقمي لحسابك في `.env` |
| لا تظهر التواريخ صحيحة | اضبط `TIMEZONE` (مثل `Europe/Istanbul`) |

## الأمان

- لا توجد أسرار داخل الكود؛ كل شيء في `.env` (وهو مستثنى في `.gitignore`).
- كل استعلامات SQL مُعلَّمة (parameterized) عبر SQLAlchemy.
- صلاحية الأدمن تُفحص عند **كل** أمر وزر إداري.
- التوكن يُحجب تلقائياً من السجلات.
- لا تُخزَّن بيانات شخصية غير ضرورية: لا يُحفظ أي مستخدم قبل اشتراكه، ويُحفظ فقط المعرّف والاسم واسم المستخدم.
